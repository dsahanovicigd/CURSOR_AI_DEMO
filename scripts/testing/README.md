# Testing Scripts

Scripts for running tests.

## Scripts

- **run_tests.sh** - Run Flask API test suite (pytest)
- **run_unittest.sh** - Run Flask API unit tests

## Usage

```bash
# Run all tests
./scripts/testing/run_tests.sh

# Run unit tests only
./scripts/testing/run_unittest.sh
```

## Notes

- These scripts were moved from `flask_api/` directory
- Update paths if needed when running from project root
