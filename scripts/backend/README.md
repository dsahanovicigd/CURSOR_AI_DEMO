# Backend Scripts

Flask API specific scripts for development and management.

## Scripts

- **start.sh** - Start Flask API server
- **stop.sh** - Stop Flask API server
- **setup.sh** - Setup Flask API development environment

## Usage

```bash
# Setup environment
./scripts/backend/setup.sh

# Start server
./scripts/backend/start.sh

# Stop server
./scripts/backend/stop.sh
```

## Notes

- These scripts were moved from `flask_api/` directory
- Original functionality preserved
- Update paths if needed when running from project root
